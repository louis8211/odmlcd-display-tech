RGB and SPI Interfaces for Small MCU Panels

Hardware · Part of the RONEN DISPLAY technical library

Parallel RGB / 8080

MCU parallel buses (8080/6800) write directly to the panel controller's GRAM. They are simple and fast for small panels but use many GPIOs, which gets painful above a few inches.

SPI for low pin count

SPI uses few wires and suits tiny industrial modules driven by resource-limited MCUs. The trade is lower pixel throughput, so it fits static UI, not video.

Choosing for the MCU

Match the bus to your MCU's peripherals and available pins, then pick a controller board that speaks it. See controller board selection and the interface primer.
