Display Resolution and Aspect Ratio

Fundamentals · Part of the RONEN DISPLAY technical library

Resolution basics

Resolution is the pixel grid: 800x480 (WVGA), 1024x768 (XGA), 1280x800 (WXGA) and so on. More pixels show more detail but need more interface bandwidth and a larger controller framebuffer. Most industrial TFT modules ship in a small set of standard resolutions chosen for cost and long-term availability.

Aspect ratio and UI

Aspect ratio is width over height. Legacy HMIs often use 4:3; modern UI and video favour 16:9. Pick the ratio that matches your application graphics so you avoid stretching or letterboxing the layout.

Pixel pitch and viewing distance

Pixel pitch (mm between pixels) and size set pixels-per-inch. A panel viewed up close wants higher PPI for crisp text; a wall-mounted display can use larger pitch. Tie this to the selection checklist for your install.
